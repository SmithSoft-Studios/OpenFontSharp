Roboto-Regular.fonttools.gz is a compressed outline reference generated from
Roboto-Regular.ttf with fontTools 4.68. It records every glyph's expanded point
coordinates and on-curve flags, contour endpoints, advance width and left side
bearing. Woff2RealFixtureTests compares the converted Roboto WOFF2 output against
this independent reference for every glyph. The Roboto fixtures are licensed
under Apache-2.0; see LICENSE.txt.
