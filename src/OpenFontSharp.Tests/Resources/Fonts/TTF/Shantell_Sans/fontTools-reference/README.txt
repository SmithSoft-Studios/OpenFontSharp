These small static reference fonts were generated from the adjacent
ShantellSans-VariableFont_BNCE,INFM,SPAC,wght.ttf with fontTools 4.68:
instantiateVariableFont followed by fontTools.subset for A and V, with hinting
and layout features omitted. The reference coordinates are wght=700;
wght=500/BNCE=-50/INFM=75/SPAC=25; and the maximum user coordinate on all four
axes (wght=800/BNCE=100/INFM=100/SPAC=100).

Each reference has three glyphs (.notdef, A and V). RealVariableFontReferenceTests
compares the subsetter's retained outlines and advances with these independently
instantiated fonts; the largest point difference is 1 font unit at mixed axes
(A, point 22 X), and 0 font units at the other two instances.
The source and modified references are covered by the adjacent SIL Open Font
License 1.1 file.
