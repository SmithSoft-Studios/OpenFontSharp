OpenFontSharp-Lato-Positioning.ttf is a small subset of Lato Regular 2.015
(Debian package fonts-lato 2.015-1), from https://github.com/google/fonts/tree/main/ofl/lato.
It was subset with fontTools 4.68 for A, V, T, o and combining cedilla, retaining
the kern and mark layout features and omitting hinting. The primary font names
were changed to OpenFontSharp Reference to honor the reserved name "Lato".

The fixture is licensed under SIL Open Font License 1.1; see OFL.txt. HarfBuzz
position references are recorded in RealFontGposShapingTests.
